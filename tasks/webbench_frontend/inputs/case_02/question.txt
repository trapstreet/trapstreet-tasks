## Steps

### Step 1
Generate a page with HTML/CSS/JS (ES module) files. 'index.js' and 'index.css' are used by 'index.html'. The '.table' table element contains thead, and tbody elements. thead contains 1 row and 3 columns (th). tbody contains 2 rows and 3 columns (td). All cells (th and td) are border-box and contain content like 'cell x y'.

### Step 2
Add a context menu (class menu, absolute position, min-width/height 100px) in the page. Display context menu when right-clicking on the table. Hide the menu when clicking anywhere else on the page, including the menu space. Save codes to es-module 'common/menu.js' imported by 'index.js'.

### Step 3
When right clicking td cell in tbody row, add menu item 'Add Row Before' (class menu-item-add-row-before), 'Add Row After' (class menu-item-add-row-after),  'Drop Row' (class menu-item-drop-row). Click these menu items to do the corresponding actions.

### Step 4
When right clicking th cell in thead row, add menu item 'Add Column Before' (class menu-item-add-column-before), 'Add Column After' (class menu-item-add-column-after), 'Drop Column' (class menu-item-drop-column). Insert th cell in thead row and td cell in tbody row.

### Step 5
Click to select and highlight a cell which is added class 'picked'. Save codes to 'common/table.js' imported by 'index.js'.

### Step 6
If no picked cell, press Arrow keys to the first cell (top-left one). Press Arrow keys to change the picked cell to the next possible one. Save codes to 'common/key.js' imported by 'index.js'.

### Step 7
If no picked cell, press Tab and 'Shift+Tab' key to the first cell. Press Tab key to change the picked cell to the next one. The rules are from left col to right col, change to the left of next row if no next cell in current row; change to the first cell of the table if no next row. The rules for 'Shift+Tab' is the opposite of the rules of Tab key.

### Step 8
Add menu item 'Pick Row' (class menu-item-pick-row) for body cell. Add menu item 'Pick Column' (class menu-item-pick-column) for header cell. Press 'Cmd+A'(windows 'Ctrl+A') to select all cells. Press Escape key to unselect the picked cells.

### Step 9
Press 'Delete' or 'Backspace' key to clear all picked cells content.

### Step 10
Click with Shift key to select a rectangle of cells. Press 'Shift+Arrow' key to extend the picked cells by one more/less row/col.

## How the result is checked

`src/` is served as static files (`npx serve src`), and the page is exercised in Chromium: it is loaded, clicked, typed into and inspected. Only files under `src/` are taken from your answer; everything else comes from the starter project above.
